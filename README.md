# Automate Check
Are you sometimes unsure to repeat an activity manually or build an automation? Here is the solution, the automate-check. With this tool you can compare your amount of time for the manually workload to the time for implementing a automatic-process.

**[Try the calculator here](https://suckatcoding-com.github.io/automate-check)**

Inspired by the great [XKCD](https://xkcd.com/1205/) comics
